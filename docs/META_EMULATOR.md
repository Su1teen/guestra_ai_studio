# Режим «как WhatsApp / как Instagram»

Studio отправляет сообщения гостя в CRM в формате вебхука Meta (WhatsApp Cloud API и Instagram) и подписывает их так же,
как Meta (`X-Hub-Signature-256`). Ответы отеля (ИИ или сотрудника) CRM возвращает в Studio через транспорт Studio.
На демо видно то же, что на настоящем канале: окно 24 часа, шаблоны, статусы доставки, реакции.

Режим работает **только на тестовом окружении** (`STUDIO_ENVIRONMENT` = `test` или `sandbox`). Без переменных ниже
вкладка «Как WhatsApp» показывает, что режим выключен, и Studio работает как раньше.

## Переменные

Studio:

| Переменная | Значение |
| --- | --- |
| `STUDIO_META_EMULATOR_WEBHOOK_URL` | адрес вебхука Meta в тестовой CRM: `https://<crm>/api/webhooks/meta` |
| `STUDIO_META_EMULATOR_SECRET` | общий секрет подписи — тот же, что `META_APP_SECRET` тестовой CRM |
| `STUDIO_META_CALLBACK_TOKEN` | токен ответов (не короче 32 символов) |
| `STUDIO_META_WA_PHONE_NUMBER_ID` | номер WhatsApp эмулятора (любой код, тот же, что в учётной записи канала в CRM) |
| `STUDIO_META_IG_ACCOUNT_ID` | аккаунт Instagram эмулятора (по желанию) |

Тестовая CRM:

| Переменная | Значение |
| --- | --- |
| `META_ENABLED` | `true` |
| `META_APP_SECRET` | общий секрет подписи |
| `STUDIO_META_CALLBACK_URL` | `https://<studio>/api/integrations/meta-emulator/replies` |
| переменная токена | значение `STUDIO_META_CALLBACK_TOKEN`; её имя указывается в учётной записи канала |

В CRM на странице «Каналы» добавьте учётную запись с источником «AI Studio (тест)», каналом WhatsApp или Instagram,
номером или аккаунтом эмулятора, объектом и именем переменной токена.

## Сценарии показа

1. **Ночной поток и утреннее распределение.** Отправьте несколько сообщений с разных номеров гостей. В поле
   «Отправлено минут назад» укажите время вне рабочих часов, чтобы показать отметку о позднем получении. Утром
   руководитель распределяет чаты в CRM.
2. **Оплата 50 %.** Гость просит номер на даты. ИИ называет условия гарантии из PMS (процент предоплаты) и передаёт
   оформление оплаты сотруднику.
3. **Напоминание за 48 часов.** Для брони с заездом через двое суток CRM отправляет напоминание. В Studio видно сообщение
   отеля и его статусы: «Доставлено», «Прочитано».
4. **Отмена со штрафом.** Гость пишет об отмене позже срока бесплатной отмены. ИИ называет срок из PMS и передаёт решение
   об удержании сотруднику.
5. **Окно 24 часа.** Если с последнего сообщения гостя прошло больше суток, CRM не отправит обычный ответ и попросит шаблон.
   Шаблонный ответ в Studio подписан «[Шаблон …]».

Переписка эмулятора хранится в памяти Studio и пропадает после перезапуска: это демонстрационный канал, а не журнал.
