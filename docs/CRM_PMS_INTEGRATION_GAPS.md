## Events and inspector endpoints

PMS reservation created/confirmed/changed/cancelled updates CRM external reservation refs; stay check-in/out updates verified lifecycle; services and guest request statuses update context; folio charge/payment settled/refunded/voided update authorized finance projection. Authorization is separate from settlement. Event consumer keeps source revision and immutable event receipt; older revisions cannot overwrite newer facts or human ownership. Exact names require discovery of final PMS contract, not inferred audit entity.action.

Required read APIs: CRM guest-message changes + automation/allowedActions + verified identity + Request/Offer/external PMS links + sanitized tool events; PMS principal/property/scopes + Guest/Reservation/Stay/Service/Folio/payment facts + operation-key lookup + immutable event cursor; n8n execution by correlation/run + deployment hash + safe timing/tool summaries. Inspector endpoints grant no business write capabilities.
