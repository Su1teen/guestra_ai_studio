# CRM v2 adapter

Source pin: CRM `aea540523c0e4dcf79f32fe11df5e3466ed9cdff`, PMS `0dc4adeb508eb4bc6bc73d64848883eb6f115626`. Audited actual router/DTO/security/service/recovery/messaging/media/sandbox/context definitions and their optional SQL. Base `CRM_API_URL` includes `/api/integrations/agent`, header `x-crm-api-key`; PMS discovery base includes `/api/v1/connect`, header `x-api-key`. Runtime validators are in `server/crm-v2-contracts.ts`, adapter methods in `server/crm-v2.ts`.

Every scoped request includes `propertyId`, `channel=simulator`, `externalUserId`, `conversationId`. Adapter property is pinned to configured property; all v2 calls attest environment/property/tenants/deployment before use. Missing credentials/optional schema/flags fail closed. Explicit `CRM_API_VERSION=v1` retains the simulator inbound/transcript compatibility path; incompatible v2 never falls back.

Business mutations stay on CRM's facade and are prepared only for an attested isolated test/sandbox environment in this delivery. CRM enforces tool scopes, current AI ownership, delivered proposal, later guest consent, expiry, revisions and native idempotency; Studio/n8n must not reproduce/override those guarantees. No direct PMS write adapter or `PMS_COMMAND_SECRET` exists here.

HTTP 200 is not business success. Pending requires scoped operation polling; completed includes PMS authoritative snapshot; rejected and safe uppercase `PRICE_CHANGED`, `QUOTE_EXPIRED`, `REVISION_CONFLICT`, `IDENTITY_CONFLICT`, confirmation and ownership errors remain distinct. Studio callback business completion also checks the CRM operation receipt.

Changes are drained in bounded pages (50 per poll, remaining pages on the next poll), transactionally persisted with cursor, merged by CRM message ID/sequence. Duplicate/overlapping/out-of-order HTTP completion is safe. A malformed backwards/nonadvancing/unsorted cursor is rejected. Delivery/media updates replace the same snapshot; tombstones are retained and excluded from guest view. Local attempt files overlay only matching `externalFileId` evidence, preserving upstream processing/transcript/delivery state. The v1 path continues its paged reconciliation and filters staff notes, with no deletion of old snapshots.

Customer context is freshly fetched; n8n execution history and Simple Memory are not authoritative memory. Inspector maps only proven run correlation/execution refs. Raw arguments, staff notes, arbitrary metadata, tokens and hidden reasoning are excluded. Test harness fixtures demonstrate client-side contracts; real backend consent, ledger and AI execution remain EXTERNAL_E2E_PENDING.

Read polling shares a five-second successful attestation cache keyed by endpoint/credentials/environment/mapping. Explicit discovery and sandbox mutation preflight force fresh attestation; upstream guards still apply on every API request. Concurrent same-conversation polls share one read and a 1.5-second cooldown; writes never use that cooldown. Plan a credential-level rate budget for simultaneous active conversations (current CRM limit 120/minute) and back off on 429. Legacy tool aliases are normalized before intersection with authoritative allowedActions through approvedTools; they never grant new permissions. withTrace sends only validated correlation/execution/prompt/deployment references in query fields recognized by CRM middleware.
